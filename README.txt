How to run
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet access is recommended for the Google Fonts import and external source links. The main website layout and local illustrations work without a framework.

Included features
- Responsive desktop, tablet, and mobile layout
- Mobile hamburger navigation
- Active section navigation
- Search panel
- Dark mode
- Scroll reveal animations
- Interactive warning-sign accordions
- Interactive safety tabs
- Statistics cards with source links
- Philippine laws cards with official source links
- Myth or Fact quiz with feedback
- FAQ accordion
- Help and resources section
- References section
- Back to Top button
- Accessible labels, skip link, keyboard-friendly controls, and descriptive image text

Research sources
Statistics and legal references were checked against Philippine government or official legal sources during project preparation, including PSA, PCW, Lawphil, and the Philippine government's emergency hotline directory.

Important
This is an educational website project. It does not provide legal advice or replace professional or emergency services.
